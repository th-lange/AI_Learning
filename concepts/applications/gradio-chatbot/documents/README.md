# Technical Documentation

Place your technical documentation files in this folder. The application will automatically load and use them to answer technical support questions.

## Supported File Formats

- **PDF files** (.pdf)
- **Text files** (.txt, .md, .rst)
- **Structured data** (.json, .yaml, .yml, .xml, .csv)

## How It Works

When the application starts, it will:
1. Scan this folder for all supported files
2. Load the content from each file
3. Use the combined content as a knowledge base to answer technical questions

## Examples

You can add files like:
- Installation guides (installation_guide.pdf)
- API documentation (api_docs.md)
- Troubleshooting guides (troubleshooting.txt)
- FAQ documents (faq.md)
- Configuration references (config_reference.yaml)

Simply drop your files in this folder and restart the application to use them.
